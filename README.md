# Personal Portfolio Website

A responsive personal portfolio built with **HTML5 and CSS3 only** (no JavaScript, frameworks, or backend) for the HTML & CSS Internship project.

## Features
- Semantic HTML5 structure (header, nav, main, section, article, aside, footer)
- Sticky navigation with anchor links to Home, About, Skills, Projects and Contact
- Hero section with call-to-action buttons
- 8 skill chips and 3 project cards with technologies used
- Contact section with email, GitHub and LinkedIn links, plus a visual-demo-only form
- CSS variables for the colour palette, Flexbox and Grid layouts
- Hover and keyboard focus states, mobile and tablet media queries
